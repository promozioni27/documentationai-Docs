## Dashboard and navigation

Use the dashboard to surface the most important content first. Keep the navigation simple and predictable so users can jump between records, search, and organization without extra training.

<Tabs>
  <Tab title="Dashboard" icon="layout-dashboard">

    The dashboard should show recent items, status summaries, and shortcuts to frequent actions. Keep the layout lightweight and focus on what users need most.

  </Tab>
  <Tab title="Navigation" icon="chevron-right">

    Group links by task, not by internal system structure. A user should understand where to click without reading a long explanation.

  </Tab>
  <Tab title="Saved views" icon="bookmark">

    Saved views help users return to a filtered list, such as recent records, favorites, or items needing attention.

  </Tab>
</Tabs>

## Record management examples

When you document record handling, show the fields users see most often: name, status, date, owner, and notes. Keep the guidance short and action-oriented so users can complete tasks quickly.

<CodeGroup tabs="JavaScript,Python,cURL">

  const response = await fetch("https://api.example.com/records", {

  import requests

  response = requests.post(
      "https://api.example.com/records",
      headers={
          "Content-Type": "application/json",
          "Authorization": "Bearer YOUR_API_TOKEN"
      },
      json={
          "title": "Annual review",
          "status": "open",
          "category": "health",
          "notes": "Created from the dashboard"
      }
  )

  record = response.json()
  print(record["id"])

## Search and organization

Search works best when your content uses consistent labels, clear titles, and simple categories. Encourage users to search by terms they actually remember, not by internal system jargon.

| Area | Recommended practice | Why it helps |
|------|----------------------|-------------|
| Titles | Use short, specific names | Users find items faster |
| Tags | Apply 3 to 5 useful tags | Filters stay manageable |
| Status | Keep statuses consistent | Lists are easier to scan |
| Notes | Write brief, descriptive notes | Context is easier to recover |

## Best practices

<Callout kind="tip">

If you want users to move quickly, reduce choices on each screen and keep labels consistent across the dashboard, search, and record detail views.

</Callout>

- Use one primary action per screen.
- Keep list filters visible and predictable.
- Write field labels in plain language.
- Show recent activity when history matters.
- Make saved views easy to edit and reuse.
